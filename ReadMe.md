# WuwaTappo Helper

**繁體中文** | [English](./README.en.md)

Windows 桌面助手，支援 WuwaTappo 自動按鍵與領取寶箱。

## 使用

1. 安裝 Python 3.11 以上版本，包含 pip、Tkinter 與 `py` 啟動器。
2. 首次使用執行 `Setup.bat` 安裝套件。
3. 開啟 WuwaTappo，再執行 `Start.bat`，允許管理員權限。
4. 開啟需要的功能，選擇按鍵、速度與點擊方式。
5. 按「開始」執行，「暫停」停止；關閉視窗即可結束。

## 設定

- **自動按鍵**：持續送出所選按鍵，領箱冷卻期間也會繼續。
- **自動領箱**：達到點擊門檻且寶箱可領取時執行。
- **前台／背景**：前台會移動滑鼠；背景不移動滑鼠，失敗不會自動改用前台。
- **☀／☾、EN／中**：切換深淺色及介面語言。設定會自動保存。

## 注意

- 自動按鍵會送到目前前景程式，請選未被其他程式使用的 F13～F24。
- 寶箱須保持可見，遊戲視窗不要最小化；計數器被其他視窗遮住仍可辨識。
- 主要點擊數由輸入累積，並以 OCR 定期校正；首次校正前可能顯示「讀取中」。
- 設定、領箱進度與冷卻保存在 `runtime.json`。
